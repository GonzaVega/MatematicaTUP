## 🔢 Parte 1 - Desarrollo Matemático

A partir de los DNIs de los integrantes del grupo, se generaron conjuntos de dígitos únicos para cada persona. Se realizaron operaciones entre conjuntos como:

- Unión
- Intersección
- Diferencia simétrica

Además, se redactaron expresiones lógicas en lenguaje natural vinculadas con los conjuntos y sus propiedades. Estas expresiones se incluyeron en el PDF teórico y algunas se implementaron en el código.

También se realizaron diagramas de Venn para representar gráficamente las relaciones entre los conjuntos.

## 🐍 Parte 2 - Desarrollo en Python

El programa en Python incluye las siguientes funcionalidades:

- Ingreso de DNIs y generación automática de conjuntos de dígitos únicos.
- Operaciones de conjuntos (unión, intersección, diferencia, diferencia simétrica).
- Conteo de frecuencia de cada dígito.
- Suma total de los dígitos de cada DNI.
- Evaluación de condiciones lógicas (por ejemplo: "dígito compartido", "diversidad numérica alta").
- Análisis de años de nacimiento: pares, impares, bisiestos.
- Función para verificar si un año es bisiesto.
- Producto cartesiano entre los años de nacimiento y las edades actuales.
